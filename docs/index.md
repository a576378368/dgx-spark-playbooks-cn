# DGX Spark Playbooks 中文版

欢迎使用 DGX Spark Playbooks 中文版！

本项目是 NVIDIA DGX Spark 官方 Playbooks 的中文翻译版本，提供详细的中文文档来帮助中国用户更好地理解和使用 DGX Spark 设备。

## 📚 文档内容

本中文版包含了所有官方 Playbooks 的翻译，涵盖以下内容：

- **NVIDIA**：各种 AI/ML 工作负载的设置指南
  - Comfy UI
  - 连接多台 DGX Spark
  - CUDA-X 数据科学
  - DGX Dashboard
  - FLUX 微调
  - Isaac Sim
  - JAX 优化
  - VLM WebUI
  - Llama.cpp
  - LLaMA Factory
  - LM Studio
  - 多代理聊天机器人
  - 多模态推理
  - NCCL
  - NeMo 微调
  - Nemotron
  - NIM
  - NVFP4 量化
  - Ollama
  - Open WebUI
  - **OpenClaw** 🦞
  - OpenShell
  - 投资组合优化
  - PyTorch 微调
  - RAG 应用
  - SGLang
  - 单细胞 RNA 测序
  - Tailscale
  - TRT-LLM
  - 文本到知识图谱
  - Unsloth
  - VS Code
  - VSS 代理
  - 和更多...

## 🚀 快速开始

### 本地预览

```bash
cd translated-site
pip install mkdocs mkdocs-material
mkdocs serve
```
