## 概述

## 基本概念

OpenClaw（原名 Clawdbot 和 Moltbot）是一个**本地优先**的 AI 代理，在您的机器上运行。它将多种功能组合到单个助手中：它记住对话，适应您的使用，持续运行，使用来自您的文件和应用的上下文，并且可以使用社区**技能**扩展。

在您的 DGX Spark 上**完全运行** OpenClaw 及其 LLM 可以保持您的数据隐私并避免持续的云 API 成本。DGX Spark 非常适合此用途：它运行 Linux，设计为保持开启，并且具有**128GB 内存**，因此您可以运行大型本地模型以获得更好的准确性和更强大的行为。

## 您将实现的目标

您将在您的 DGX Spark 上安装 OpenClaw 并连接到本地 LLM（通过 LM Studio 或 Ollama）。您可以使用 OpenClaw Web UI 与您的代理聊天，并可选地连接通信渠道和技能。代理和模型完全在您的 Spark 上运行 - 除非您添加云或外部集成，否则数据不会离开您的机器。

## 流行用例

- **私人秘书**：通过访问您的收件箱、日历和文件，OpenClaw 可以帮助管理您的日程安排，起草回复，发送提醒，并查找会议时间。
- **主动项目管理**：通过电子邮件或消息检查项目状态，发送状态更新，以及跟进或发送提醒。
- **研究代理**：结合网络搜索和您的本地文件，生成具有个性化上下文的报告。
- **安装助手**：使用终端访问搜索应用/库，运行安装，并调试错误（建议使用较大的模型）。

## 开始前须知

- 基本使用 Linux 终端和文本编辑器
- 可选：熟悉 Ollama 或 LM Studio（如果您计划使用本地模型）

## 重要：安全和风险

AI 代理可能引入实际风险。阅读 OpenClaw 的指南：[OpenClaw Gateway 安全](https://docs.openclaw.ai/gateway/security)。

主要风险：

1. **数据暴露**：个人信息或文件可能被泄露或窃取。
2. **恶意代码**：代理或连接的工具可能使您面临恶意软件或攻击。

您无法消除所有风险；后果自负。**关键安全措施：**

- **强烈推荐**：在专用或隔离系统（例如，干净的 DGX Spark 或 VM）上运行 OpenClaw，并且仅复制代理需要的数据。不要在您的主要工作站上运行此，特别是当您有敏感数据时。
- 使用**专用账户**给代理而不是您的主要账户；仅授予代理所需的最小访问权限。
- 仅启用您**信任的技能**，最好是社区验证的技能。提供终端或文件系统访问的技能会显著增加风险。
- **关键**：确保 OpenClaw Web UI 和任何通信渠道**绝不**在没有强身份验证的情况下暴露于公共互联网。使用 SSH 隧道或 VPN 如果远程访问。
- 在可能的情况下，使用防火墙规则或网络隔离**限制代理的互联网访问**。
- **监控活动**：定期审查代理的日志和执行的命令。

## 先决条件

- 运行 Linux 的 DGX Spark，连接到您的网络
- 终端（SSH 或本地）访问 Spark
- 对于本地 LLM：足够的 GPU 内存用于您的选择模型（参见操作说明获取大小指导；DGX Spark 的 128GB 支持大型模型）

## 时间与风险

- **持续时间**：安装和首次模型设置大约需要 30 分钟；模型下载时间取决于大小和网络（gpt-oss-120b 约为 65GB，在较慢连接上可能需要更长时间）。
- **风险等级**：**中到高**-代理可以访问您配置的文件、工具和渠道。如果您启用终端/命令执行技能或连接外部账户，风险显著增加。没有适当的隔离，此设置可能会暴露敏感数据或允许代码执行。**始终遵循上述安全措施。**
- **回滚方案**：您可以停止 OpenClaw 网关并通过相同的安装脚本或通过删除其目录来卸载；如果需要，分别卸载 Ollama 或 LM Studio。

## 操作说明

> [!CAUTION]
> **在继续之前，请查看概述选项卡中的安全风险。** OpenClaw 是一个 AI 代理，可以访问您的文件，执行命令，并连接到外部服务。数据暴露和恶意代码执行是真实风险。**强烈推荐**：在隔离系统或 VM 上运行 OpenClaw，使用专用账户（不是您的主要账户），并且绝不暴露没有身份验证的仪表板到公共互联网。

## 步骤 1. 在您的 DGX Spark 上安装 OpenClaw

在您的 DGX Spark 上，打开终端并运行官方安装脚本。这将在您的 Linux 系统上安装 OpenClaw 及其依赖项。

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

下载依赖项后，OpenClaw 将显示**安全警告**。阅读风险；如果您接受它们，使用箭头键选择**是**并按回车。

## 步骤 2. 完成 OpenClaw 入门

按照以下提示进行操作。

1. **快速入门与手动**：选择**快速入门**。

2. **模型提供者**：要使用**本地模型**（DGX Spark 的推荐），转到列表底部并选择**暂时跳过**-您以后将配置模型。要改用云模型，请选择提供者并按照其说明进行操作。

3. **按提供者过滤模型**：选择**所有提供者**。在下一个默认模型提示中，选择**保留当前**。

4. **通信渠道**：您可以连接渠道（例如，消息）以便在离开机器时使用机器人，或选择**暂时跳过**以后配置。

5. **技能**：我们建议暂时选择**否**。您以后可以从 Web UI 或 Clawhub 添加技能，但在您测试基础知识后。

6. **Homebrew**：如果您被提示安装 Homebrew，请选择**否**-Homebrew 仅适用于 macOS，在 Linux 上不需要。

## 故障排除

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| `openclaw` 命令未找到 | OpenClaw 未正确安装 | 重新运行安装脚本或检查 PATH |
| `curl: (7) Failed to connect` | Spark 不可达 | 检查 NVIDIA Sync 连接和网络 |
| 模型下载失败 | 网络问题或 Hugging Face 不可达 | 检查网络连接和重试 |
| GPU 未检测到 | CUDA 驱动程序问题 | 验证 `nvidia-smi` 和驱动程序安装 |

> [!NOTE]
> DGX Spark 使用统一内存架构（UMA），允许 GPU 和 CPU 内存之间的灵活共享。一些软件仍在赶上 UMA 行为。如果您意外遇到内存压力，您可以尝试刷新页面缓存（在共享系统上小心使用）：
```bash
sudo sh -c 'sync; echo 3 > /proc/sys/vm/drop_caches'
```

有关最新的平台问题，请参阅 [DGX Spark 已知问题](https://docs.nvidia.com/dgx/dgx-spark/known-issues.html) 文档。
