# 关于

## 项目介绍

本项目是 [DGX Spark Playbooks](https://github.com/NVIDIA/dgx-spark-playbooks) 的中文翻译版本。

## 目标

为中文用户提供准确、易懂的 DGX Spark 使用指南，降低 AI/ML 开发的学习门槛。
